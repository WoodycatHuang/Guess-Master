# Guess Master

A number guessing game built with Expo and React Native. Pick a difficulty, guess the secret number, and climb the scoreboard.

## How to play

1. Choose **Easy** (1–50), **Medium** (1–100), or **Hard** (1–500).
2. Enter your guess — you'll get **Higher** or **Lower** hints.
3. Win before you run out of attempts to earn points.

## Getting started

```bash
npm install
npm start
```

Then press `i` for iOS simulator, `a` for Android emulator, or scan the QR code with Expo Go on your phone.

## Tech stack

- Expo SDK 56
- React Native
- TypeScript
